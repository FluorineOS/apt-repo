FluorineOS APT Repository

Official signed package repository for FluorineOS on Debian 13 (trixie).

Repository details

  • URL: https://fluorineos.github.io/apt-repo
  • Suite: trixie
  • Component: main
  • Architecture: amd64

Set up the repository

First install GnuPG and download the archive public key. Confirm the displayed fingerprint is exactly the value shown below before installing it.

sudo apt update
sudo apt install -y curl gpg
curl -fsSLo /tmp/fluorineos-archive-keyring.asc https://fluorineos.github.io/apt-repo/fluorineos-archive-keyring.asc
gpg --show-keys --with-fingerprint /tmp/fluorineos-archive-keyring.asc
# Confirm the fingerprint below, then install the key:
gpg --dearmor --output /tmp/fluorineos-archive-keyring.gpg /tmp/fluorineos-archive-keyring.asc
sudo install -D -m 0644 /tmp/fluorineos-archive-keyring.gpg /usr/share/keyrings/fluorineos-archive-keyring.gpg
sudo tee /etc/apt/sources.list.d/fluorineos.sources > /dev/null <<'EOF'
Types: deb
URIs: https://fluorineos.github.io/apt-repo
Suites: trixie
Components: main
Architectures: amd64
Signed-By: /usr/share/keyrings/fluorineos-archive-keyring.gpg
EOF
sudo apt update
sudo apt install fluorine-keyring

After setup, fluorine-keyring maintains the archive keyring and source definition.
