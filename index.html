FluorineOS APT Repository

Official signed APT package repository for FluorineOS.

Repository URL: https://fluorineos.github.io/apt-repo
Distribution: trixie
Components: main
Architectures: amd64, all

Adding the Repository

Install the fluorine-keyring package, then add the source:

# Install the keyring package first
sudo apt-get install fluorine-keyring

# Add the repository source
echo "Types: deb
URIs: [https://fluorineos.github.io/apt-repo]
Suites: trixie
Components: main
Architectures: amd64
Signed-By: /usr/share/keyrings/fluorineos-archive-keyring.gpg" | sudo tee /etc/apt/sources.list.d/fluorineos.sources

# Refresh the package index
sudo apt update

Archive Keyring

Public key fingerprint: DCF8D117141143E65F930B55206E495540B36253

Download the armored public key:

wget https://fluorineos.github.io/apt-repo/fluorineos-archive-keyring.asc

Or install via the fluorine-keyring package which places the keyring at:

/usr/share/keyrings/fluorineos-archive-keyring.gpg
